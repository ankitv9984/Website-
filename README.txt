# SignatureWeb.in Website

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Replace hello@signatureweb.in in index.html and script.js with your real email.
4. Replace demo work cards with your own project screenshots.
5. Upload the folder to GitHub Pages, Netlify, or another static hosting service.

The design uses:
- HTML
- CSS
- JavaScript
- Responsive mobile navigation
- Scroll reveal animation
- Contact form mailto action

Theme:
- White background
- Green headlines/accent
- Black body text
- SignatureWeb.in branding
